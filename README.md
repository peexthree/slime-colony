# LUMIVORE: THE LIVING FRACTAL

> Ты не выживаешь в этом мире. Ты поглощаешь его, чтобы стать им.

**Биоэволюционный рогалик** — Змейка × Spore × Vampire Survivors × Physarum.  
Технологии: WebGPU Compute (120k Physarum Agents) + PixiJS v8 + Web Audio API.

## Запуск
```bash
npm install
npm run dev   # http://localhost:5173
npm run build
```
WebGPU нужен Chromium 113+ или Firefox с `dom.webgpu.enabled` (только localhost/HTTPS).

## Игровой цикл
- Ведёшь особь мышью, WASD, геймпадом или виртуальным джойстиком
- Сферы ДНК убитых врагов дают опыт, биомассу и удлиняют хвост
- Хвост = ресурс и оружие; арсенал из 6 видов вооружения при **жёстком лимите 3 слотов**: оружие родного генома открывается по уровню, чужого - на 4 уровня дороже. Споровые цисты (мины) - капстоун поздней стадии (13 ур., ДНК Мицелия 2+)
- **Резонанс генома**: 2+ оружия одной ветки дают пассивку сборки (Вермис - хлыст, Химера - урон, Мицелий - регенерация, Симбионт - скорость атаки)
- Быстрый сбор сфер разгоняет Симбиотический Резонанс до x3.0

## ДНК-матрица
Сфера ДНК врага несёт цвет своего генома:
- **ВЕРМИС** — кинетика, длина и мощь хвоста (оружие: шипы, жвала)
- **ХИМЕРА** — плазма, взрывной урон и нестабильные мутации (оружие: нова)
- **МИЦЕЛИЙ** — споры, регенерация и нейрозахват врагов (оружие: аура, цисты-мины)
- **СИМБИОНТ** — магнетизм, фаза и скорость реакции (оружие: электроорбиты)

## Великие Гибриды
При 3 уровнях ДНК в двух ветках открывается гибрид, всего 6. Итоговая форма забега - **строго один гибрид за прогон**:
- **Плазменный Левиафан** — Кольцо Смерти наносит x4 урона и аннигилирует обычных врагов внутри
- **Уроборос-Паразит** — враги, убитые хвостом, прирастают живыми сегментами
- **Фазовый Змей** — хвост перехватывает вражеские снаряды и швыряет их обратно
- **Споровый Реактор** — Нова заражает врагов спорами, их тела детонируют цепной реакцией
- **Ионный Колосс** — электроорбиты бьют дугами молний по ближайшим врагам
- **Пси-Сеть** — био-узлы захватываются быстрее, а ваши узлы бьют лазерами

## Кольцо Смерти
Замкни траекторию хвоста вокруг врагов — полигон схлопывается и поражает всё внутри (включая Гнёзда спор).

## Метаморфоз и 15 локаций
Заполни шкалу биомассы и убей Титана масштаба — камера отдаляется, мир физически расширяется, палитра и узор среды сменяются.  
**Лестница Эволюции** (лор: зонд «ЕвроКорп-3» упал на планету Ξ-9, и его капля прорастает через всё живое):  
Первичная Капля → Агар-Матрица → Кровеносный Тракт → Лимфатический Прилив → Внутренний Океан → Костный Лабиринт → Синаптическая Пустошь → Выдох Носителя → Грибные Тайги → Ржавые Дюны → Континентальный Разлом → Полярный Щит → Небесный Планктон → Ионосфера → Фрактал Бесконечности.

## Physarum-штаммы и био-узлы
- Свой штамм: +25% к скорости движения и регенерация хвоста
- Вражеский штамм растворяет хвост в 1.8 раза быстрее
- Био-узлы (5 на старте, +3 за каждую локацию) захватываются удержанием зоны (~3 с); захваченная башня получает **био-щит на 18 с**, затем её защищает гарнизон: одиночный монстр почти бессилен, толпу из 2+ особей башня держит дольше, а вход игрока восстанавливает её энергию. 2+ своих узла образуют регенерирующую нейросеть

## Биолаб и Кодекс
- **Биолаб** — мета-прогрессия в `localStorage`: постоянные мутации сохраняются между забегами
- **Кодекс** — бестиарий и каталог штаммов; открытые записи дают пассивные бонусы в забегах
