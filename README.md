# LUMIVORE: THE LIVING FRACTAL

> Ты не выживаешь в этом мире. Ты поглощаешь его, чтобы стать им.

**Bio-Evolutive Roguelite** - Змейка x Spore x Vampire Survivors x Physarum.
Технологии: WebGPU Compute (120k Physarum Agents) + PixiJS v8 + Web Audio API.

## Запуск
```bash
npm install
npm run dev   # http://localhost:5173
npm run build
```
WebGPU нужен Chromium 113+ или Firefox с `dom.webgpu.enabled` (только localhost/HTTPS).

## Игровой цикл
- Ведёшь организм мышью или WASD
- Души убитых врагов дают опыт и ДНК
- Хвост = ресурс и оружие
- Волны густеют со временем

## ДНК-матрица
Душа врага несёт цвет своего генома:
- 🐍 **ВЕРМИС** - кинетика, рост хвоста
- 🧪 **ХИМЕРА** - оружие, плазма
- 🌿 **МИЦЕЛИЙ** - споры, территория
- ⚡ **СИМБИОНТ** - магнетизм, фаза

## Гибриды
При 3 уровнях ДНК в двух ветках открывается гибрид, всего 6:
- **Плазменный Левиафан** - гигантский хвост несёт плазменный заряд и выжигает всё вдоль траектории
- **Уроборос-Паразит** - замкнутый хвост-кольцо вытягивает биомассу из пойманных врагов
- **Фазовый Змей** - фазовые рывки сквозь толпу без потери хвоста
- **Споровый Реактор** - залпы сеют споры, захватывающие территорию
- **Ионный Колосс** - магнетизм стягивает врагов в плазменный залп
- **Пси-Сеть** - споровые узлы связываются в сеть и бьют по всей захваченной территории

## Кольцо Смерти
Замкни траекторию хвоста вокруг врагов - полигон схлопывается и выжигает всё внутри.

## МЕТАМОРФОЗ
Заполни шкалу биомассы и убей Титана масштаба - камера отдаляется (зумаут), мир меняет масштаб и палитру.
Шкалы: Первичная Капля -> Кровеносный Тракт -> Внутренний Океан -> Континентальный Разлом -> Фрактал Бесконечности.

## Physarum-штаммы
- Свой циановый след: +25% скорость и регенерация хвоста
- Вражеское фиолетовое поле растворяет хвост
- 7 био-узлов захватываются плотностью штамма

## Биолаб
Мета-прогрессия в localStorage: постоянные мутации сохраняются между забегами.
